# Guia de planejamento antropométrico

Este documento organiza um protocolo de estudo, não ensina autoavaliação nem define dimensões para fabricação. A geometria incluída no projeto é esquemática e não deve ser ajustada para uso clínico com base neste guia.

## Antes de medir

1. Defina a pergunta de pesquisa e justifique por que cada medida é necessária.
2. Obtenha aprovação ética/institucional quando aplicável e consentimento informado, sem coerção.
3. Faça a coleta com profissional habilitado, em ambiente privado e acessível, respeitando conforto, identidade e possibilidade de interromper a sessão.
4. Use instrumentos apropriados, higienizados e calibrados. Registre instrumento, unidade, postura, protocolo, operador e incerteza.
5. Atribua um código aleatório ao registro. Mantenha dados identificáveis separados e protegidos; não publique fotos ou dados brutos identificáveis.

## Roteiro de sessão

1. Confirme o consentimento e explique cada etapa antes de qualquer contato físico.
2. Registre apenas metadados não identificáveis indispensáveis ao estudo, como código da sessão, data aproximada e versão do protocolo.
3. Com orientação profissional, identifique os marcos anatômicos relevantes ao objetivo aprovado. Não use este documento como referência para localizar estruturas no corpo.
4. Registre cada dimensão definida no protocolo, unidade e método. Repita a leitura conforme o protocolo e anote discrepâncias em vez de escolher silenciosamente um valor.
5. Interrompa se a pessoa pedir, sentir dor ou desconforto. Não faça inferências diagnósticas.
6. Revise a planilha com a pessoa responsável pela coleta, remova identificadores e aplique a política institucional de retenção e descarte.

## Campos sugeridos para uma ficha anonimizada

| Campo | Registro |
| --- | --- |
| Código aleatório da sessão | Sem nome, iniciais ou data de nascimento |
| Protocolo e versão | Identificador e revisão aprovados |
| Instrumento | Tipo, identificação e calibração |
| Dimensão e unidade | Conforme protocolo aprovado |
| Leituras repetidas | Valores separados e método de repetição |
| Operador e condições | Código do operador e observações relevantes |
| Consentimento e aprovação | Referência guardada separadamente, com acesso restrito |

## Uso dos dados

Dados antropométricos só devem ser usados no escopo aprovado, com governança e revisão profissional. Não insira medidas pessoais no SCAD para gerar uma peça de uso corporal. Qualquer dispositivo destinado a uma pessoa exige avaliação clínica, projeto de engenharia, ensaios, validação e conformidade regulatória próprios.
